Enable Android resources for the Robolectric offline test classpath (fixes the v0.8.7 Stale AAPT ID Resource$NotFoundException on AGP 8.x).

Specifically: the 4 OfflineVoiceInputE2ETest unit tests that touched SettingsManager.getSystemPrompt() and PromptsRepository.getActivePromptBody() (which internally call context.getString(R.string.label_prompt)) were throwing android.content.res.Resources$NotFoundException: String resource ID #0x7f0f0072 because AGP 8.x flipped the unit-test isIncludeAndroidResources default to false — Robolectric's binary resource backend found an empty ResourceTable while the AAPT-generated R.class held stable IDs. The fix sets testOptions.unitTests.isIncludeAndroidResources = true so src/main/res/ is bundled into the test classpath. Verified 60/60 Robolectric unit tests pass (previously 56/60; 4 stuck on Resources$NotFoundException).

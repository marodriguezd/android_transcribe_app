New in v0.8.8

• Multi-prompt post-processing: keep several AI prompts (tone, language, list-cleanup, etc.) and switch the active one before each dictation. Edit, duplicate, import and export prompts from the new "Manage prompts" screen.

• The default app prompt is now editable and exportable. Customise it once and your tweaks persist; one-tap "Reset to default" returns to the built-in form.

• The default "My words" dictionary is now editable and exportable as a regular user dictionary. Duplicate it to keep a personal copy, export it to share across devices, or reset it back to empty.

• Welcome dialog redesigned for first-run clarity: each option now shows the model size next to its label ("Fast / 0.6B", "Fastest / 180M", "Use without / No model") and is ordered from least to most capable.

• Bundled model assets: the debug APK now ships Parakeet (0.6B) and Canary (180M) ONNX weights inside the package, so first-run users can pick either variant without a Wi-Fi download.

• Fix for a crash triggered when the welcome dialog rendered multi-line button text (StaticLayout IndexOutOfBoundsException).

• Defensive fixes: dialog dismissal lifecycle on Activity pause, Activity-context leak hardening throughout SettingsManager / PostProcessor / DictionaryManager, and post-processing prompt ordering. AGP 8.x Robolectric resource-loading fix restores offline unit-test stability.

• Existing fixes retained from v0.8.7: settings leak hardening, Activity-context hygiene, network-error bug for notifications channel.

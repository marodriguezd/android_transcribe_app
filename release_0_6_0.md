# Release v0.6.0

## 🔧 Improvements & Bug Fixes
- **UI Fix:** Fixed an issue where the microphone icon appeared white instead of blue on the very first startup.
- **AI Prompt Refinement:** Updated the default post-processing AI prompt to a perfectly translated English template.
- **Translation Prevention:** Added strict explicit rules to the AI prompt instructing the model to maintain the original language perfectly to prevent unwanted translations (e.g. Spanish input mistakenly translated into English).
